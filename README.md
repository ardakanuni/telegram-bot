# ربات تلگرام انجمن علمی مهندسی عمران دانشگاه اردکان

این بسته برای استقرار نسخه فعلی Python ربات روی Railway آماده شده است.

## فایل‌ها
- `main.py`: سورس ربات با مدیریت برنامه‌ها (ویرایش، حذف/آرشیو) و دریافت کد ملی ۱۰ رقمی.
- `requirements.txt`: وابستگی‌های Python
- `railway.json`: دستور اجرای سرویس در Railway
- `Procfile`: تعریف فرایند worker
- `.env.example`: نمونه متغیرهای محیطی؛ توکن واقعی داخل آن قرار ندهید.

## استقرار در Railway
1. این پوشه را در مخزن خصوصی GitHub آپلود کنید.
2. در Railway یک پروژه جدید از مخزن GitHub بسازید.
3. در تنظیمات سرویس، متغیرهای زیر را در بخش Variables وارد کنید:
   - `BOT_TOKEN`: توکن واقعی BotFather
   - `ADMIN_IDS`: `5837430827`
   - `PUB_CHAT_ID`: اختیاری؛ شناسه عددی گروه/کانال تیم نشریه. اگر خالی باشد، طبق منطق فعلی پیام‌های نشریه به اولین ادمین می‌روند.
   - `CARD_INFO`: متن شماره کارت و نام صاحب کارت، فقط در Railway Variables
   - `CONTACT_LINK`: `https://t.me/IEarduni_admin`
   - `DATABASE_PATH`: `/data/bot.db`
   - `TZ`: `Asia/Tehran`
4. از بخش Volumes یک Volume بسازید و آن را در مسیر `/data` متصل کنید. این کار برای ماندگاری SQLite هنگام redeploy/restart مهم است.
5. دستور Start باید `python main.py` باشد. فایل `railway.json` همین دستور را تنظیم می‌کند.
6. پس از Deploy، لاگ سرویس را بررسی کنید. ربات با Polling اجرا می‌شود؛ برای این سورس نیازی به دامنه یا تنظیم Webhook نیست.

## اطلاعات کد ملی
- هنگام تکمیل پروفایل، کد ملی ۱۰ رقمی دریافت و از نظر رقم کنترل بررسی می‌شود.
- کد ملی در SQLite ذخیره می‌شود، در پروفایل نمایش داده می‌شود و در خروجی CSV ثبت‌نام‌کنندگان و پیام رسید برای مدیران قرار می‌گیرد.
- تغییر ساختار دیتابیس به‌صورت خودکار انجام می‌شود؛ ستون `national_id` به دیتابیس قبلی اضافه می‌شود و اطلاعات قبلی حذف نمی‌شوند.
- کد ملی داده حساس است؛ فقط در صورت نیاز واقعی آن را جمع‌آوری کنید و دسترسی به Railway، دیتابیس و فایل‌های CSV را محدود نگه دارید.

## امنیت
- توکن ربات، اطلاعات کارت بانکی و فایل `bot.db` را در GitHub قرار ندهید.
- توکن را فقط در Railway Variables وارد کنید.
- اگر قبلاً توکن را در جایی عمومی منتشر کرده‌اید، از BotFather آن را تعویض کنید.

## نکته درباره هزینه
اجرای شبانه‌روزی روی Railway ممکن است پس از پایان اعتبار آزمایشی نیازمند پلن/اعتبار پولی باشد. رایگان بودن دائمی تضمین‌شده نیست.
